# Prebuilt Syspm Callback (T2GBE4M) Implementations Release Notes
Syspm callbacks provides a set of prebuilt implementations for handling DeepSleep entry and exit for supported drivers on T2GBE4M family of chips.

### What's Included?
This release of the syspm-callbacks includes support for the following drivers:
* DMA
* NVM
* SCB UART
* TCPWM

### What Changed?
#### v1.0.0
* Initial release for CYT2BLx support.
